    Class HtmlEntityDecoder

    Streaming decoder for HTML entities.

    When the entity fits inside the current chunk (the common case), the lookup runs directly on the chunk via the same length-probe scheme as the synchronous decoder; chunk-boundary runs use a reusable character buffer.
