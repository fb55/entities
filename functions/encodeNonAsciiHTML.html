Function

encodeNonAsciiHTML

function encodeNonAsciiHTML(input: string): string

Defined in encode.ts:188

Encodes all non-ASCII characters, as well as characters not valid in HTML documents using HTML entities. This function will not encode characters that are valid in HTML documents, such as #.

If a character has no equivalent entity, a numeric decimal reference (eg. &#252;) will be used.

Parameters

input: string

Input string to encode.

Returns

string
